Démarrer

  1. Ouvrez un TP ci-dessus, de préférence dans Chrome, Firefox ou Edge sur ordinateur. Python tourne directement dans votre navigateur : il n'y a rien à installer.
  2. Le premier chargement prend 30 s à 1 min (téléchargement de Python, NumPy, OpenCV...). Les suivants sont plus rapides.
  3. Complétez les cellules marquées TODO. Exécutez une cellule avec Ctrl+Entrée (Cmd+Entrée sur Mac). Les cellules qui en dépendent se mettent à jour automatiquement. Les encadrés verts ✅ vous indiquent quand une fonction est correcte.

Enregistrer votre travail

  • Enregistrez régulièrement avec Ctrl+S (Cmd+S sur Mac). Votre code est alors conservé dans ce navigateur, sur cet ordinateur : en rouvrant la même page plus tard, vous retrouvez votre travail.
  • Cette sauvegarde est effacée si vous videz les données du navigateur ou utilisez une fenêtre de navigation privée, et elle ne vous suit pas sur un autre ordinateur. Téléchargez donc aussi votre notebook (voir ci-dessous) à la fin de chaque séance.
  • Pour repartir de l'énoncé d'origine, ajoutez ?reinitialiser à la fin de l'adresse de la page (par exemple …/nom_du_tp/?reinitialiser). Attention, votre sauvegarde est alors effacée.

Rendre votre notebook

  1. Enregistrez (Ctrl/Cmd+S).
  2. Ouvrez le menu ☰ en haut à droite du notebook, puis Export… → Python → Notebook source → Export notebook source. Un fichier .py est téléchargé.
  3. Renommez-le NOM_Prenom_TP1.py (avec le numéro du TP) et déposez-le à l'endroit indiqué par votre enseignant.

Vous pouvez aussi exporter en HTML (même menu) pour garder une copie lisible avec les graphiques. Le fichier .py rendu peut être rouvert avec marimo installé localement (marimo edit NOM_Prenom_TP1.py).
